# Security policy

## Supported versions

Kitezh is a demonstration identity platform. Security fixes are applied to the latest `main`
branch and the latest published release when practical.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's private
[Security Advisory](../../security/advisories/new) form and include:

- a clear description of the issue and its impact;
- the affected commit, release, endpoint, or configuration;
- reliable reproduction steps or a minimal proof of concept; and
- any suggested mitigation.

We will acknowledge a report when we can reproduce or assess it, coordinate a fix, and credit
the reporter when they want to be credited. Do not include real credentials, access tokens, or
production data in a report.
